# Beef Carcass Explorer

An interactive beef-cut learning site for RMCTC Culinary Arts. The site is a
single static HTML file with no build step or runtime dependencies.

## Run locally

Open `index.html` in a browser, or serve the project directory:

```sh
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Features

- Explore an interactive beef carcass diagram and primal-cut details
- Practice identifying cuts in a ten-round game
- Review the study guide, vocabulary cards, and knowledge check
- Responsive layout with light and dark themes
